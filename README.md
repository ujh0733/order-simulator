# order-simulator

배달 플랫폼 관리자 페이지를 소재로, **대량 주문 트래픽에서 발생하는 병목을 직접 만들고 해결해 나가는** 학습을 위해서 작성한 토이프로젝트 입니다.

가장 단순한 구조로 시작해 강제로 부하를 주고, 실제로 병목 형성이 발생하는 지점을 확인하고 뒤 그 지점에 대해 해결책을 고민하여 적용해 보려고 합니다.

---

## 시나리오

가상의 배달 플랫폼을 운영한다고 가정합니다.

- 서울시 실제 음식점 데이터를 수집해 가맹점 정보를 구성합니다.
- 관리자가 **시간당 주문 건수**를 설정하면, 그 목표치에 맞춰 주문이 자동으로 생성됩니다.
- 생성된 주문은 접수 → 조리 → 배차 → 완료 상태를 거칩니다.
- 관리자 페이지에서 주문 현황을 모니터링하고 주문 내역을 검색합니다.
- 사용자(고객) 페이지는 없이 관리자 페이지에서 시뮬레이션만 진행합니다.

주문 생성량을 의도적으로 증가시켜 시스템의 병목 지점을 직접 경험해 보는 것을 목표로 했습니다.

## 진행 원칙

**설정은 기본값으로 시작**
커넥션 풀 크기, MySQL 설정 파일, JPA 옵션 등을 미리 튜닝하지 않고, 실제로 문제가 발생한 뒤에 해당 설정을 수정해 보면서, 변경 전후를 비교합니다.

**의도적으로 병목을 발생하여 개선해보는 것을 목표**
Kafka나 Elasticsearch와 같은 대규모 트래픽에 적합한 플랫폼을 먼저 도입하지 않습니다. 기존 구조로 처리가 안 되는 상황을 발생, 확인한 다음에 도입합니다.
최종 목표는 실제 테스트를 해 보고 도입 근거를 측정값으로 남기는 것을 목적으로 합니다.

**스키마 변경은 Flyway로만 합니다.**
`ddl-auto`는 `validate`로 고정합니다. 인덱스를 언제 어떤 이유로 추가했는지가 마이그레이션 파일에 이력으로 남습니다.

## 데이터 시딩

대량 데이터는 Gradle 태스크(`group = data`)로 생성합니다. DB(`docker compose -f docker/docker-compose.yml up -d`)를 띄우고 앱을 한 번 기동해 Flyway 마이그레이션을 적용한 뒤 아래 순서로 실행하세요.

| 순서 | 대상 | 명령 | 비고 |
|---|---|---|---|
| 1 | 가게 (서울 일반음식점) | `./gradlew collectSeoulRestaurants` | 프로젝트 루트 `.env`에 `SEOUL_API_SERVICE_KEY=<공공데이터포털 디코딩 서비스키>` 필요 |
| 2 | 고객 + 배송 주소 | `./gradlew seedDummyUsers` | 아래 참고 |
| 3 | 라이더 | (자동) | Flyway 마이그레이션(V22)이 37만 명까지 생성 |
| 4 | 주문 이력 | `./gradlew seedOrderHistory` | 실행할 때마다 100만 건 추가(전부 `COMPLETED`, 최근 90일에 분산). 1~3번 데이터가 먼저 있어야 함 |

### 고객 시더 (`seedDummyUsers`)

인자 없이 실행하면 **총 유저 수가 950만 명이 될 때까지** 생성하고, 숫자를 넘기면 그 값을 **목표 총 유저 수**로 사용합니다.

```bash
# 기본값: 총 950만 명까지
./gradlew seedDummyUsers

# 총 100만 명까지
./gradlew seedDummyUsers --args=1000000
```

- 목표는 "추가할 수"가 아니라 **총량 기준**입니다. 이미 있는 유저는 유지하고 부족한 만큼만 채우므로, 목표 이상이 이미 있으면 아무것도 생성하지 않고 종료합니다(기존 데이터를 지우지도 않습니다).
- 유저마다 주소를 1~3개(평균 2개) 함께 생성합니다. 950만 명이면 주소는 약 1,900만 건입니다.
- 2,000명 단위로 커밋하므로 중간에 중단돼도 커밋된 만큼은 남고, 다시 실행하면 이어서 채웁니다. 규모가 크면 시간이 오래 걸립니다(950만 명은 수십 분).

## 데이터 출처

- **서울시 일반음식점 인허가 정보** — 서울 열린데이터광장
  가맹점의 상호, 주소, 업태, 영업 상태 정보를 사용합니다.
- **더미 데이터** — 메뉴, 가격, 배달비, 영업시간 등 공공데이터에 없는 항목은 더미 데이터를 생성합니다.
- **주문 데이터** — 실제 거래 데이터가 아닌 시뮬레이터가 생성합니다.
